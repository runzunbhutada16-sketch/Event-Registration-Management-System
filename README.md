# Event Registration Management System

## 📌 Project Description

The Event Registration Management System is a Python-based application designed to manage event registrations efficiently.

The system allows users to register for events and helps manage participant and event information using a database.

## 🎯 Objectives

- Manage event information
- Register participants for events
- Store participant details
- Manage registration records
- Provide an organized database system

## 🛠️ Technologies Used

- Python
- SQLite / SQL
- PyCharm
- GitHub

## 📂 Project Files

- `DBMS.py` – Main Python program
- `EventDB.sql` – Database/SQL file

## ⚙️ Features

- Event registration
- Participant management
- Database management
- View and manage registration details
- User-friendly interface

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in PyCharm.
3. Make sure Python is installed.
4. Open `DBMS.py`.
5. Run the Python program.
